# UCP Playground

A small, browser-only learning demo for the [Universal Commerce Protocol](https://ucp.dev/). It walks through a fictional purchase across discovery, cart construction, OAuth identity linking, payment authorization, and post-purchase order management.

The JSON shown in the interface is intentionally simplified and fictional. It is not a production UCP implementation and does not process payments or identities.

## Run locally

Open `index.html` in a browser, or serve this directory with any static-file server.
